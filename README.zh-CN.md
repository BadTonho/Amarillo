本代码库包含 **Amarillo 本地后台通信服务 (Daemon) 与 VS Code 扩展源码**。本目录为桥梁工具本体工程，不应当用作游戏开发的 Roblox 工作区目录。

## 项目核心模块组成

- `src/daemon/` 与 `src/mcp-proxy/`: HTTP 通信后台服务与 MCP 代理工具的核心 TypeScript 代码与服务驱动管理源码。此处编译生成的 `.js` 文件仅为运行构建产物。
- `vscode-extension-src/`: 针对 VS Code 开发环境深度集成的官方插件 TypeScript 源码。
- `src/plugin-src/`: 严格按照执行优先顺序编制的 Roblox Studio 内挂载插件 Luau 模块集，提供强韧的启动握手、双向拉取通信及 UI 管理等核心逻辑。
- `src/plugin/Amarillo.lua`: 由编译脚本联合合成后的可直连单文件版 Roblox Studio 插件包，专供 Studio 本体、VS Code 扩展装载以及 VSIX 自动封包阶段使用。
- `src/daemon/**/*.js`、`src/mcp-proxy/**/*.js`、`vscode-extension/*.js`、`tests/*.js` 以及 `scripts/*.js`: 由 TypeScript 编译器自动化生成并归宿自管理体系的中间和落地执行 JavaScript 代码脚本。
- `tests/`: 项目高覆盖度集成与单元自动化 TypeScript 测试工程（已完美覆盖并全绿通过全部 295 项测试：涵盖项目配置文件解析、系统握手自启、健康诊断医疗检查、MCP 通信交互及防攻击校验保护）。

## 系统当前设计架构

- 由单实例本地核心驱动服务（Daemon）提供中央统帅能力，统一受理来自 Roblox Studio 插件与 VS Code 开发集的基本通信、鉴权隔离与高效调度管理。
- 内建的 MCP 协议集成架构绝不胡乱开闭多套重复充裕的冗余服务，告别端口浪费与后台多实例资源占用互冲。
- 指令 `Amarillo: Start Bridge` 启动或维持工作环境下的唯一桥接守护服务器，并在根工作区极速生成与同步易用的标准化集成适配依赖及启动程序入口（支持任意现代化 AI IDE Client 端完美免挂额外守护直接对接 `stdio -> HTTP` 代理互换链）。
- 指令 `Amarillo: Configure MCP for Workspace` 与 `Amarillo: Configure Codex MCP` 允许一键重建专属 MCP 对接配置依赖结构，同时具备调用本机命令行直接注册并映射入 Codex 等极简助手能力。
- 领先行业的**多应用地点场景 (Place-Based Derived Projects)** 支持架构与精准路径绑定挂载防护；从机制层面保证跨级敏感及高风险代码注入修改绝不在意外地点上野性覆写甚至发生破坏误炸资产风险。
- 精干无声的增量快照和解对比与原生层默认属性（Default Value normalizing）自愈洗白；排除非活跃视觉属性振颤对硬盘引发过度物理耗损拉扯！
- 系统通用通信体系绑定与互联目标网络端口固定设定为：**`8323`**（默认坚定并严格死链闭合锁定处于物理回路网卡本机地址：`127.0.0.1` 之中！）。

## 为广大开发者倾心定制的应用实施指引

1. 借助 VS Code 编辑器平齐载入并敞开您真实的 Roblox 游戏独立系统工程目录。
2. 呼叫并运行编辑器上方快捷面板中的命令配置组：`Amarillo: Install Roblox Studio Plugin` 完成快速挂载。
3. 接着于相同控制窗口里轻挥按下一键开端互建令：`Amarillo: Start Bridge` 完成通道待命。
4. 切换进入咱们创作阵地核心大讲台——Roblox Studio 工具栏内定位激活 `Amarillo` 小工具视图窗并轻戳夺目的 **Connect**（连接） 按钮。
5. 放心地于界面间顺其自然随心驱动点击 `Send Files to Studio` (打向游戏阵营)，亦或使用 `Receive Files from Studio` (自引擎抓揽战果)，或直接将主导重托无缝交接给身边绝世的人工智能大模型伴侣！

## 地理隔离型级联演变体系架构（Place-Based Derived Projects）

Amarillo 把对多主客空间地界并在一块协作时的无限包容关爱演进成了不可思议并具神功大成之典范式的 `核心本元母舱 + 多相子级衍生展点 (base project + derived projects)` 之合体美域。
- 只须动一纸朱砂批令置字句 `abstract: true` 镌勒刻铸入祖祠中心核心 `.project.json` 中，倾力总览谱造普罗全世仰奉不替浩荡公共宏伟根系林云和圣规！
- 尔后自各相别域驻足的 `.project.json` 长房枝孙中轻宣传承神技引入至臻奥义字诀 `extends` ，顿使所有直连各驻军分营皆瞬间蒙祖萌德畅沐传承祖宗精髓全局家当之外却复凭自己绝代自足灵气拓自创自建天地独拥风华！
- 万不可思议至神来一指定山间的是此举不争半刻清幽 —— 哪怕切换战场征伐至远在他乡新场景片场之中仅听候唤迎面送来的区区数字烙记一枚小小名徽证标 `placeId` 即可如意灵动知往来识天地般无阻穿梭于不同片场剧目神会融归属于契和天地心契共演场！！
- 分道各自成王而不相牵怒惹，处处可心安闲调控只专于自己那片自为战之极土界城规划。
